Haeufig gestellte Fragen

Wie erstelle ich einen neuen Tag?

Oeffnen Sie ein Foto, tippen Sie auf das Tag-Symbol und geben Sie Ihren Tag ein. Bestaetigen Sie mit dem Haken.

Werden meine Daten in der Cloud gespeichert?

Nein. Alle Daten bleiben ausschliesslich auf Ihrem Geraet.

Wie kann ich einen Tag loeschen?

Wischen Sie in der Tag-Ansicht auf einen Tag nach links und tippen Sie auf Loeschen.

Welche iOS-Version wird benoetigt?

SnaptagApp erfordert iOS 16.0 oder hoeher.

Wie kann ich Fotos importieren?

Tippen Sie auf das Plus-Symbol und waehlen Sie Aus Fotobibliothek oder Foto aufnehmen.
